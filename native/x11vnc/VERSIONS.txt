Remote Control host agent (static x11vnc + vdrelay)
===================================================

Built by build.sh in Alpine containers, one tarball per host architecture:

  agent-x86_64.tar.gz     linux/amd64
  agent-aarch64.tar.gz    linux/arm64 (QEMU user emulation on an x86_64 build machine)

Each holds three files: x11vnc and vdrelay (static, stripped, musl) and `version` (x11vnc's own
version line). The tarballs are embedded in VirtDeck.Core (see VirtDeck.Core.csproj) and their
hashes are in SHA256SUMS. They ARE committed: a normal build of VirtDeck never runs build.sh.

Built from source (tarballs committed in src/, hashes in SOURCES.sha256):

  x11vnc          0.9.17    https://github.com/LibVNC/x11vnc/archive/refs/tags/0.9.17.tar.gz
  LibVNCServer    0.9.15    https://github.com/LibVNC/libvncserver/archive/refs/tags/LibVNCServer-0.9.15.tar.gz
  libXau          1.0.12    https://www.x.org/releases/individual/lib/libXau-1.0.12.tar.xz
  libXdamage      1.1.7     https://www.x.org/releases/individual/lib/libXdamage-1.1.7.tar.xz
  libXrandr       1.5.5     https://www.x.org/releases/individual/lib/libXrandr-1.5.5.tar.xz
  libXinerama     1.1.6     https://www.x.org/releases/individual/lib/libXinerama-1.1.6.tar.xz
  vdrelay         (ours)    vdrelay.c

Linked from Alpine's own static packages (image alpine:3.24.2; the exact package versions of a
build are recorded in packages-<arch>.txt): musl, libX11, libxcb, libXdmcp, libXext, libXtst,
libXfixes, libXrender, libXi, zlib, libjpeg-turbo.

LibVNCServer is built without TLS, crypto backends, websockets, systemd, PNG or LZO: SSH is the
transport and the authentication, and the client asks for Tight (zlib + JPEG) only. x11vnc is
configured without SSL, crypto, avahi, XRECORD, XTRAP, XCOMPOSITE, DPMS, v4l, fbdev and uinput.

Updating a version: replace the tarball in src/, regenerate SOURCES.sha256 (in src/:
`sha256sum * > ../SOURCES.sha256`), adjust the names in build-in-alpine.sh and this file, run
build.sh, review licenses-found/ into licenses/, and commit the new agent tarballs.
